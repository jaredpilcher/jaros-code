# Intent

This spec exists to measure the *ceiling* of pure harness-deepening on the hardest
multi-step-repo class: if we stack every cheap non-model lever at once — retrieved
direct-dependency context, one worked before/after example from a different corpus task, and
an explicit numbered decomposition plan — into a single maximal-help prompt, can the model
crack tasks it fails at 0/8 raw? The probe exists precisely to settle whether more scaffolding
is still the answer for this class or whether the wall is genuine generation capability that
only a different-distribution model (or a reduction) can clear. Its explicit verdict tells the
convergence loop which way to spend the next Jetson-hour.

It converges toward the Prime Directive by combining the L1 (decomposition), L3 (retrieval),
and L4 (experience-recall via a worked example) ladder rungs into one honest ceiling test —
the disciplined way to prove a rung is exhausted before escalating to L6 routing. It holds
Tenet 3 as a hard line: the worked example is always drawn from a DIFFERENT sha, the target
task's own oracle/solution is never in the prompt, and the hidden oracle scores only after
generation — so a "does not help, route to a decorrelated model" verdict is an honest,
load-bearing finding, not a defeat to paper over.
